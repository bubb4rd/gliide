Front-end UI designer

Fully Remote

Description

The Front-End UI/UX Designer designs, prototypes and builds clear, accessible web interfaces for the Wonka Public Schools (WPS) family and staff portals. The role turns district data (school boundaries, bus routes, enrollment counts, test-score trends and facility conditions) into fast, friendly web and mobile experiences for parents, teachers and planners.

Working in the district's cloud environment alongside a mapping and analytics partner, the designer turns Figma wireframes, research findings and stakeholder feedback into responsive, touch-friendly web components. The priorities are helping families find what they need, keeping interactive maps and charts readable, meeting WCAG 2.1 AA and Section 508 without exception, and keeping one design system consistent across desktop, tablet and phone.

Requirements

**• UI/UX Design & Figma Prototyping: **Produce high-fidelity wireframes, interactive prototypes, user flows and design specs in Figma for new WPS features, including the school finder, bus route lookup, and the enrollment planning dashboard.

**• Responsive Mobile & Tablet Optimization:** Design and build touch-friendly layouts for phones and tablets so map layers, tables and trend charts stay readable on small screens.

**• Map & Chart UI Building:** Build front-end components, map controls (layer toggles, opacity sliders, boundary filters) and chart widgets with HTML5, CSS3/Tailwind, JavaScript/TypeScript, and web mapping libraries (MapLibre, OpenLayers, or similar).

**• Section 508 & WCAG 2.1 AA Compliance: **Make every component meet Section 508 and WCAG 2.1 AA: semantic HTML, ARIA live regions, visible keyboard focus, and high-contrast palettes for charts and maps.

**• Design System & Component Curation:** Build and maintain the WPS design system and component library on top of the U.S. Web Design System (USWDS) and district branding.

**• User Research & Usability Evaluations: **Review feedback from parents, school staff and public web forms, run usability tests, and tighten navigation.

**• Agile Collaboration & Testing: **Work with full-stack developers, data engineers and QA testers in Agile sprints (GitLab/GitHub) so shipped code matches the approved Figma designs and meets the required =80% statement test coverage.

**Experience Required**

**• Education:** Bachelor’s Degree in User Experience (UX) Design, Human-Computer Interaction (HCI), Computer Science, Graphic Design, or a related field.

**• Professional Experience Benchmark: **Minimum of 3 to 5 years (5+ preferred) designing and building public-facing web interfaces, dashboards, or map applications.

**• Map & Data Visualization Portfolio: **A portfolio with responsive web designs, interactive charts and maps, design systems, and Figma wireframes for data-heavy products.

**• Public-Sector Accessibility Experience: **Hands-on work applying Section 508 and WCAG 2.1 AA to dynamic, canvas- or SVG-heavy interfaces.

**Technical Skills Required**

**• UI/UX & Prototyping Tools:** Advanced Figma, user story mapping, and wireframing.

**• Frontend Languages & Frameworks: **Strong HTML5, CSS3 / SASS / Tailwind CSS, JavaScript (ES6+), TypeScript, and a modern framework (React, Vue, or Svelte).

**• Mapping & Charting Libraries:** Hands-on work with web mapping frameworks (MapLibre GL, OpenLayers, or Leaflet) and charting tools (D3.js or similar).

**• Accessibility Standards & Auditing: **Expertise in WCAG 2.1 Level AA, Section 508, ARIA, color contrast checks, screen-reader testing, and automated audit tools.

**• Design Systems & Frameworks: **Familiarity with the U.S. Web Design System (USWDS), design tokens, and mobile-first responsive design.

**• Agile & Version Control Tooling: **Git (GitLab / GitHub), component testing frameworks (Jest / Cypress), and Agile issue tracking (Jira).
