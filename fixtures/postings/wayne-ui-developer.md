# UI Developer - Options Market Making

Chicago

**ABOUT THE COMPANY:**

Wayne Markets is a proprietary trading firm that trades its own capital in listed options and futures. Traders, quants and engineers sit side by side here, and our pricing and execution systems are built in-house so we can quote tighter and move faster than the market.

**Overview**

We are looking for a UI developer) to join our Market Making Technology team.

You'll work with our UI developers and UX designers on Wayne Markets' next trading applications, the web platform beneath them, and our shared component library and design system.

**The role will involve**
- UI development
- Shipping new applications and adding features to existing ones
- Building modular components in React and TypeScript for our core UI framework
- Weighing in on technical direction and code review
- Working with backend developers so the screens and services fit together
- Supporting our trading applications by troubleshooting, debugging and fixing UI issues

**Must have skills and experience**
- Excellent UI development skills in JavaScript/TypeScript, including component and library development
- Real experience with, and interest in, UX and UI design principles
- Strong problem-solving skills and attention to detail
- Self-starter who can manage multiple tasks and meet deadlines

 **Desirable / nice to have**
- Experience with React, component libraries and design systems
- Experience building complex and data rich user interfaces spread across multiple desktops
- Experience working in the financial sector
- Experience using AI-powered tools to work faster.

**WHAT WE CAN OFFER YOU**
- Competitive compensation 
- Retirement plan 
- Annual discretionary bonus 
- Breakfast, lunch and snacks in the office. 
- 25 days’ annual leave
- Casual dress 
- Health and life insurance
- Monthly team events
