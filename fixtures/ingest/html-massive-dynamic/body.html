Software Engineer

MASSIVE DYNAMIC builds secure software for agencies whose work never makes the news. Our engineers sit beside analysts, field the hard questions and ship tools that hold up under pressure.

We are looking for a Software Engineer to join a small team modernizing a data-processing platform: moving batch jobs to services, writing tests where none existed and keeping the lights on while we do it. 

Responsibilities include, but are not limited to:

  • Design, build and maintain Java and Python services that move and enrich mission data.
  • Write automated tests and wire them into the team’s CI pipeline.
  • Troubleshoot production issues with operations staff and document the fixes.

Minimum Qualifications:

  • Bachelor’s Degree in Computer Science, Software Engineering or a related field.
  • Experience with Java or Python and with Linux.

Clearance Requirements:

  • Active/current TS/SCI with Polygraph.

Physical Requirements:

  • Must be able to work in an office setting for extended periods.
