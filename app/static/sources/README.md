# Source icons

The brand icons on Feed → Search's source strip (`Sources` in `$lib/ui`), bundled so the app makes no third-party
request for them. Each is the brand's own published icon, unmodified except scaled down to 64px (Lever publishes only
48px; kept as is). Fetched 2026-10-13. Shown as published: never recolored, filtered or outlined (DESIGN.md, Company
logos).
