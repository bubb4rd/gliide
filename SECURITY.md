# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security advisories:
[Report a vulnerability](https://github.com/bubb4rd/gliide/security/advisories/new) on bubb4rd/gliide. Don't open a
public issue for them.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as
practical; once a fix is released, the advisory is published with credit to you unless you'd rather stay anonymous.

## Supported versions

gliide is in early development: only the latest commit on `main` and the latest release receive fixes.

## Scope

In scope: the app, its crates and the `ez` CLI in this repository. Out of scope: the agent CLIs gliide launches
(report those to their makers) and third-party services it reads from (job boards, freehire, LinkedIn, Apify,
OpenStreetMap/OpenFreeMap).
